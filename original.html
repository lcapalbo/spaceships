Emulación del juego original

Esta página intenta cargar el ejecutable original de SpaceShips Adventure! del 2000, dentro de un emulador DOS en el navegador.

Volver al inicio Ver nueva versión Repositorio GitHub

¿Qué contiene esta página?

El archivo ejecutable original se carga desde un paquete js-dos completo que incluye también los recursos necesarios.

Si el emulador no arranca en tu navegador, puedes descargar el paquete, descomprimirlo y abrirlo localmente con un emulador DOS como DOSBox.

Sobre esta emulación

Este proyecto usa js-dos v8 con backend DOSBox para ejecutar la versión original de SpaceShips Adventure directamente en el navegador.

Todos los recursos del emulador se sirven desde este repositorio, sin depender de la CDN del proveedor.

Más información sobre js-dos en su sitio público: js-dos.com.

Gracias a la comunidad de js-dos y a los desarrolladores de DOSBox por hacer posible esta emulación.

Presiona "Iniciar emulador" para cargar el juego.

Si no hay carga automática, prueba recargando la página o descarga el paquete original.

Notas rápidas

  • La versión original es el ejecutable original de Turbo Pascal, ahora disponible para explorar.
  • La emulación se realiza con una librería JavaScript externa; puede depender del navegador y de la política de seguridad.
  • Si deseas, también puedes ejecutar el archivo localmente con DOSBox en tu sistema.
