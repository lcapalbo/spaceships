Sobre esta versión

Esta es la versión recreada del juego original de Turbo Pascal. Se ha mantenido el espíritu y gameplay del original mientras se adapta el código para ejecutarse en navegadores web modernos.

El proyecto fue desarrollado en colaboración con IA, probando su capacidad para migrar el código original y entender la lógica de un videojuego retro.

Proyecto recreado con IA y publicado en GitHub Pages desde la rama gh-pages.
