Sobre esta versión

Esta es la versión recreada con IA. Se mantuvo el espíritu y gameplay del original mientras se adaptó el código para ejecutarse en navegadores web modernos.

La interacción es por teclado, no es posible de momento jugar con pantalla táctil.

Aunque se respeta la resolución 640x480 del original, en la esquina superior derecha encontrarás un botón ⛶ para activar el modo pantalla completa.
