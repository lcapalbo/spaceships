Emulación del juego original

Esta página intenta cargar el ejecutable legacy de SpaceShips Adventure! dentro de un emulador DOS en el navegador.

Volver al sitio Ir a la versión nueva

¿Qué contiene esta página?

El archivo ejecutable original se carga desde un paquete js-dos completo desde legacy.jsdos para incluir también los recursos necesarios.

Si el emulador no arranca en tu navegador, puedes descargar el paquete, descomprimirlo y abrirlo localmente con un emulador DOS como DOSBox.

Si no hay carga automática, prueba recargando la página o descarga el ejecutable legacy.

Descargar legacy.jsdos

Notas rápidas

  • La versión legacy es el ejecutable original de Turbo Pascal, ahora disponible para explorar.
  • La emulación se realiza con una librería JavaScript externa; puede depender del navegador y de la política de seguridad.
  • Si deseas, también puedes ejecutar el archivo localmente con DOSBox en tu sistema.

Este sitio usa la rama gh-pages para publicar el proyecto en GitHub Pages.
