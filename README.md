# Migración de Turbo Pascal a web basada en IA

Esta es la migración de mi juego *SpaceShips Adventure!* original Turbo Pascal 7 (con librería gráfica BGI) a una versión HTML5/JavaScript, manteniendo la estética retro 640x480 VGA, el gameplay y controles originales.

El branch *gh-pages* contiene el sitio web del proyecto, donde pueden jugarse ambas versiones (con emulador DOS web para el original).

Los mensajes de commit mantienen los prompts usados y respuestas del agente (GitHub Copilot, usado gratuitamente desde Visual Studio Code), aclarando cuando se agregaron retoques manuales.
