# GitHub page del proyecto
## Migración de Turbo Pascal a web basada en IA

Este es el sitio para mi proyecto de migración de *SpaceShips Adventure!* a la web.

El branch *development* contiene el fuente original de Turbo Pascal y el historial de desarrollo de la nueva versión web, construida con ayuda de IA.

Los mensajes de commit mantienen los prompts usados y respuestas del agente (GitHub Copilot, usado gratuitamente desde Visual Studio Code), aclarando cuando se agregaron retoques manuales.
